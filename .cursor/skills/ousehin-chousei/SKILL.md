# 往診調整

プロジェクト: `往診調整/`。生成物は `exports/`、生成器は `scripts/generate_<月>_schedule.py`。

## 月次ワークフロー

新しい月のリスト作成時は `tasks/todo.md` のチェックリストに従う。

1. 最新の希望CSV・台帳CSVをプロジェクトルートに配置
2. `python3 scripts/import_from_csv.py`（必要なら visit_records も取込）
3. 前月スクリプトを複製 → `generate_<月>_schedule.py` / `build_<月>_schedule_html.py`
4. 医師枠・片山実施日・ドライバーを `records/` または希望CSVで確認して更新
5. 生成 → HTML確認 → 手動調整 → 再生成
6. レビューを `tasks/todo.md`、教訓を `tasks/lessons.md` に記録

## 必ず読む

1. `往診ルール`（医師・出発・定員・期限）
2. 最新の希望CSV（日列 **TRUE=NG** / FALSE=候補。完了TRUE=希望入力済）
3. 最新の編集用台帳CSV（住所）
4. `.cursor/rules/project-core.mdc`（データ正本・優先順位）

|------|-----|------|----------------|
| 三原千砂子 | b484 | **片山** | 花輪または鳥越。月曜NGなら土曜・鳥越 |
| 木村一久 | b357 | **鳥越** | 花輪（月曜11時以降NGなら花輪AM・11時前終了） |
| 渡部光子 | b138 | 花輪・片山 | **鳥越のみ**。土曜14時以降 |

## 期限

- 介護・自費: 最終実施の **2ヶ月後月末**
- 医療: **ちょうど30日後**。期限前に1回目必達。コメントや月初配置なら同月2回目で期限延長

## 調整方針

1. 期限・**医師NG**（上記固定3名）・**時間帯NG**を最優先
2. 花輪は最大5。超過分は片山へ（片山実施日のみ。**片山NGの患者は片山へ振らない**）
3. **同住所・同建物・近接エリアは可能な限り同日かつ連続訪問**（下記「連続訪問の寄せ」参照）
4. 変更後は再生成し、件数・最終ETA・医療・NG衝突を検証
5. 問題・寄せきれない制約はMDの報告セクションへ

## 連続訪問の寄せ（同住所・近接）

時間帯NG・期限を満たす範囲で、**同じルート内の並び替え**により連続訪問を優先する。

### 優先順位

1. **同一住所・同一建物**（例: FH大泉の複数号室）→ 必ず連続にする
2. **同一エリアクラスタ**（`AREA_CLUSTER_ORDER` / `BUILDING_CLUSTERS`）→ 折り返しを避け連続に
3. **近接エリア**（石町↔関町など移動が短い組）→ 可能なら隣接させる

### 手順

1. 同日・同医師のルートを確認（`exports/<月>_schedule_overrides.json` または MD の動線行）
2. 同建物・同エリアが離れている箇所を特定（折り返し・遠回り）
3. 並び替え案を作り、**全患者の時間帯NG・期限**を ETA シミュレーションで検証
4. 問題なければ overrides JSON の `routes` 順序を更新
5. 再生成し、動線・ETA・NG衝突を確認

### 制約との衝突

- 時間帯NGが連続を妨げる場合は **NGを優先**
- `time_window_priority` で先頭固定の患者（三鷹先頭など）は動かさない
- 連続にできない場合は MD の報告セクションに理由を記載

## 時間帯NGの回避（余裕必須）

訪問の**開始〜終了の見込み**がNG帯に入らないよう、**ギリギリではなく余裕を持って外す**。

- 目安バッファ: **最低10分程度**（訪問想定〜15分＋移動を見込む）
- 例: 15:00–16:00 NG → **14:50までに終了**（開始はおおよそ **14:35以前**）
- 並び替えで直す。再発防止は `time_window_priority` ＋ overrides JSON
- 鳥越の **16:30帰宅**は運用目安。**割当・並び替えで厳密に合わせなくてよい**
- 患者個人の時間帯NGは必ず守る
